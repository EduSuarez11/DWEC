## Descripción
Este repositorio reúne diferentes proyectos desarrollados progresivamente con tecnologías modernas como JavaScript y TypeScript junto a HTML5, CSS y Bootstrap.

El contenido del repositorio podría ir ampliando con nuevos proyectos, funcionalidades y pruebas de desarrollo a lo largo del tiempo.
El objetivo es disponer de un espacio centralizado donde almacenar y organizar los proyectos basados principalmente en:

-   `React + Vite / Angular` - para el desarrollo del frontend.
-   `Node.js` - para la lógica y servicios del backend.
-   `Express ` - para la creación de APIs y servicios REST.
-   `MongoDB` - como sistema de almacenamiento de datos.
-   `Git y GitHub` - para el control de versiones y alojamiento de los proyectos.

---

## Tecnologías principales
### Frontend
Los proyectos frontend estarán desarrollados principalmente utilizando `React`, junto con `Vite` como herramienta de desarrollo y construcción, y Angular.

### Backend
Los proyectos que necesiten una parte servidor utilizarán `Node.js`, normalmente acompañado de `Express` para crear las diferentes rutas, servicios y APIs necesarias.

### Base de datos
Cuando sea necesario almacenar la información, se utilizará `MongoDB`, una base de datos orientada a documentos que permite trabajar con estructuras de datos flexibles. La combinación de MongoDB, Express, React y Node.js forma parte del conocido stack `MERN`.

## Finalidad del repositorio
El objetivo del repositorio es reunir y almacenar los proyectos realizados con `React, Vite, Node.js, Express y MongoDB / Angular`, manteniendo una colección organizada de aplicaciones trabajadas a lo largo del tiempo.
